Project key vs project ID

Every project has two identifiers. The dashboard shows both on the Projects list and on Environments / Flags pages under API & SDK identifiers.

Project key

Short stable name you choose when creating a project (e.g. development, checkout).

Used in the UI and for human communication. Not accepted in API URL paths today.

Project ID

UUID assigned by flag-gen (e.g. 2c9be7ab-1d09-4caa-bd54-91fdf1d34ee1).

Required in /v1/projects/:projectId/..., WebSocket projectId=, and SDK config (FLAG_GEN_PROJECT_ID). Environment paths use environment key instead.

Example path: GET /v1/projects/<project-id>/environments/development/flags

Endpoint Reference

Browser-safe list GET /v1/client/projects/:projectId/environments/:environmentKey/flags
Browser-safe evaluate GET /v1/client/projects/:projectId/environments/:environmentKey/flags/:flagKey/evaluate?userId=...
Server evaluate POST /v1/projects/:projectId/environments/:environmentKey/flags/evaluate
Backend broadcast GET /v1/broadcast/flags?projectId=...&environmentKey=...
